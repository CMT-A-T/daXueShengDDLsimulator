# 周末地狱 · 交稿倒计时

一个纯前端、离线可玩的网页小游戏：**64 小时，三篇论文，一场数学建模竞赛，一个不想动的你。**

规则和数值来自工作区的 `basic.txt` / `细节.txt`，界面是手写的 HTML/CSS/JS，没有外部依赖、没有联网请求。

![论文页](tools/shots/paper.png)

## 怎么玩

**直接双击 `index.html`** 即可（`file://` 下可运行，存档写入浏览器 localStorage）。
如果浏览器限制了本地文件，也可以在本目录起一个静态服务器：

```bash
python -m http.server 8080
# 然后打开 http://127.0.0.1:8080
```

- 开始界面会先讲剧情、六项数值和核心机制，再让你选难度。
- 每一步都以 **30 分钟** 为单位推进，界面上的数字是**这一次行动的真实预估值**（不是公式）。
- 右侧一直显示目标达成情况（普/良/完三档小方块）；顶部一直显示时间、六项数值，以及实时计算的<b>身体状态修正</b>、<b>智力修正</b>、总效率和<b>担忧</b>。
- 时间下方是「当前状态效果」：点开可以看到你现在的困倦、心情/精力/干净/饱食状态、上课、担忧和小组会效果；担忧会明确写成「心情 -x/小时」。
- 游戏内不直接写公式：点击顶部的身体状态、智力、效率或担忧，会先显示当前的计算量；再点击其中任意一行，才会显示完整公式。
- 输赢在 **周一 23:59** 结算；也可以从右上角「？」里提前结算。

## 三档目标（与文档一致）

| 项目 | 普通 | 良好 | 完美 |
| --- | --- | --- | --- |
| 电动力学（5000 字） | ≥70 分 / AI ≤30% | ≥85 / ≤25% | ≥95 / ≤20% |
| 实地考察报告（3000 字） | ≥65 / ≤30% | ≥75 / ≤25% | ≥85 / ≤20% |
| 沟通与交流（3000 字） | ≥65 / ≤50% | ≥75 / ≤40% | ≥85 / ≤30% |
| 数模竞赛 | 总进度 100% | 100% + 总分 ≥60 | 100% + 总分 ≥75 |
| 健康 | ≥70 | ≥82 | ≥93 |

三篇论文都必须写到 100% 字数；「AI 率」超过上限时，分数再高也算该项不达标。

## 公式补全说明

原始文档是纯文本，几处公式的乘除号丢失了，游戏按常规理解补全。具体计算不在文案里展开：点击顶部的身体状态、智力、效率或担忧，会先显示当前的计算量；再点击其中任意一行，才会显示完整公式。

状态阈值（每 30 分钟结算，效率相关项计入效率修正，最低 10%）：

- 困倦：效率 -15%，心情 -1
- 精力 >70：效率 +10%；精力 <20：心情 -2、健康 -1、效率 -20%
- 心情 >85：效率 +10%、健康 +1/6h、精力消耗 -10%、精力回复 +10%
- 心情 <30：效率 -20%、健康 -1/4h、精力消耗 +20%、精力回复 -20%
- 干净 >75：心情 +1/2h、健康 +1/10h；干净 <40：心情 -1/h；干净 <20：心情 -2/h、健康 -1/4h
- 饱食 <30：心情 -1/h；饱食 <10：心情 -4/h、健康 -1/h；饱食 >70：心情 +1/h、精力 +1/30min
- 饱食固定 -6/30min，睡觉或吃饭时 -4/h；干净固定 -1/30min
- 周一上课（08:00–11:30、14:00–16:00）：效率 -50%，每 30 分钟额外 -4 精力；只能写/改论文、AI、推数模、玩游戏、休息、吃零食或认真听课；不能吃饭、睡觉、运动、洗澡、点外卖、开数模小会
- 担忧：每 30 分钟扣心情 = 1.2 × 第 n 天 × ((论文剩余均值 + 2×数模剩余)/3) / 2；周六/周日/周一的 n = 1/2/3；睡觉（深睡/标准睡眠）时不生效

补充解释：

- **数模「智力难度」** 按「智力 ÷ 难度」实现（难度 48 / 60 / 78），队友同理，身体状态修正取 1。
- **AI 写作**：一次把整篇写到 100%，分数 +50~80、AI 率 +70~100，都是随机；所以 AI 是赌局——好骰能冲完美，烂骰基本只能救到良好。进度已满时 AI 无用，按钮会禁用。上课时 AI 只加 800 字，分数/AI 率按实际进度增量结算。
- **修改论文**：同一篇论文的所有修改（A/B/C 都算）共享一个递减计数，第 n 次效果 ×0.8^(n-1)；所以别把修改次数浪费在已经救不回来的地方。
- **写论文接近 100% 时**：只按剩余进度结算分数和 AI 率（字数可以继续超出），不会因为一次 30 分钟行动把“超额部分”也算成分数。
- **数模第一次行动**：文档说「不花费时间、仍消耗精力」，因此只扣精力、不推进时钟，弹出分工选择；分工时智力较高的队友会承担难度更高的那块。
- **队友**：8:00–22:00 之间工作，每天 10 个「半小时格」（=5 小时），22:00–08:00 不工作；每开一次小组会（8:00–22:00，上课时不行），当天工作时长 +2 小时；两人都完成后会一起帮你，你的数模效率 +40%，且「寻求帮助」不可用；总体进度 100% 后，小组会改为直接增加数模总分（第 n 次效果 ×0.8^(n-1)）。
- **第一次小组会**才能看到队友进度与粗略智力（区间长度随机 3~6），第二次起准确；每次 60% 概率心情 -2。
- **队友询问进度**：自己的部分没做完时，开小组会有 30% 概率触发；白天如果 6 小时没触发过，每 30 分钟还有 4% 概率。新增「嫌他们烦」选项：心情 -13、精力 -11，队友不再询问，但两人效率永久 -10%。
- **困倦**：开局自带；白天累计休息 ≥2 小时，或一次睡够 6 小时且不是凌晨 1 点后才睡，可消除。
- **外卖被偷**的「再找找」按 30 分钟一次计，50% 找到。
- **上课**不再自动消耗时间：周一两段课是「效率 -50%、只能做少数行动」的时间窗口；课前记得垫肚子，上课时只能靠零食顶饿（舍友来要零食的概率升到 50%）。
- **担忧**：论文按每篇 `1-进度` 取平均，数模按 `1-总体进度/100`；开局全空时约为 -1.2/h，越接近完成越低，周一最重；睡觉（深睡/标准睡眠）免疫，稍作休息不免疫。

## 平衡说明（重要）

**标准模式（默认、推荐）**
- 主要行动的精力消耗按原文 ×0.8：写作 5 / AI 2 / 修改 7 / 数模 5 / 小会 5。
- 写作与数模的推进速度 ×1.2。
- 其余公式、消耗、回复全部保持文档原值。

**原版数值模式**
- 文档原值，没有任何校准；三天内的精力与时间更紧，适合熟悉规则后再挑战。

用贪心脚本实测新版数值（见 `tools/sim.js`）：

- `node tools/sim.js std 15`（含担忧 1.2）：0 完美、1 良好、14 失败——担忧把标准模式压得很紧；失败局多是自己的数模份额差 1~3 次，或健康没到 93；
- `node tools/sim.js raw 15`：0 完美、15 失败，自己的数模份额和 44% 队友仍是硬瓶颈；
- 加入担忧之前，标准模式曾 8/10 完美、原版人工也能完美（论文 99.1 / 90.8 / 93.4，数模 86.2，健康 95.7）；担忧 1.2 把难度明显抬高了，如果觉得太狠，把系数降到 0.8~1.0 更接近之前的强度。
- `AI=1 node tools/sim.js std 5`：3 局完美、2 局失败——把洗 AI 率从 30% 降到 24% 后，AI 路线回到了「高方差」而不是稳定最优。

新版的关键变化是：心情 >85 才给加成、饱食 >70 只给 +1/h 心情、睡眠回复降到 1.05/1.1、修改递减、队友每天只有 5 小时、完美健康 93、担忧 1.2——标准模式在担忧 1.2 下非常紧；人类可以打得比脚本好，但脚本几乎打不出完美。

## 已知取舍

- 「AI 率」只是纯数值，不会真的调用任何检测。
- 每日作息、课程、食堂/外卖/小店的开放时间按文档实现；周一上课是「效率 -50% + 行动限制」的时间窗口，不再自动消耗。
- 存档只保存在本机浏览器；清掉站点数据就会丢档。
- 没有音效，避免打扰。
